# Звуки лаунчера

Лаунчер сначала ищет здесь звуковые файлы (список в `sounds.json`, его пишет скрипт ниже; в git эта папка не попадает). Для каждого звука, у которого нет
файла, играет синтезированная замена.

Положить свои файлы:

```bash
tools/import-sounds.sh ~/Downloads/tvos-sounds
```

В папке файлы должны называться так (формат любой, который понимает macOS: wav, caf, aif, m4a, mp3):

| Файл | Когда звучит (как в tvOS) |
|---|---|
| `tick` | фокус перешёл на соседний элемент |
| `select` | нажатие OK (центр пульта) |
| `back` | кнопка «Назад» |
| `bump` | упор в край: дальше двигаться некуда |
| `key` | буква на экранной клавиатуре |
| `del` | «Стереть» на клавиатуре |
| `pop` | долгое нажатие: меню значка |
| `open` | появилась панель (Пункт управления, меню, алерт) |
| `close` | панель закрылась |
| `launch` | запуск приложения (если нет — `select` + `zoom`) |
| `zoom` | «вжух» при запуске приложения |
| `fling` | приложение смахнули в переключателе |
| `chime` | готово, подключено |
| `error` | ошибка (если нет — двойной `bump`) |

Скрипт сам переводит файлы в WAV 48 кГц и обновляет `sounds.json`. Громкость отдельного звука можно
поправить вручную: `{"files": {...}, "gain": {"tick": 0.7}}`.
